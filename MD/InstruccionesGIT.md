# Instrucciones generales

## Clonar Repo GTIHUB publico 
git clone https://github.com/LidiceGR/Proyectos .
## Ver si GIT esta conectado 
git remote -v
## Ver si hay pendientes de commit 
git status
## Recuperar cambios de GitHub	
git pull
## Revisar archivos modificados	
git status
## Preparar cambios	
git add .
## Guardar versión local	
git commit -m "Mis cambios"
## Subir cambios a GitHub	
git push
